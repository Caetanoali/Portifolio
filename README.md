# Portfólio Profissional | Álisson Caetano

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória e projetos como **Desenvolvedor Front-End**. O site foi construído com foco em design moderno (Dark Mode), responsividade e experiência do usuário.

## 🚀 Demonstração

O projeto está publicado e pode ser acessado através do link abaixo:
👉 **https://caetanoali.github.io/Portifolio/**

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica das seções.
* **CSS3:** Estilização personalizada, Layout Flexbox e design responsivo.
* **JavaScript (Vanilla):** Lógica para o formulário de contato e integração com APIs.

## 💻 Projetos em Destaque

O portfólio reúne aplicações que demonstram competências em manipulação de DOM, consumo de APIs e estilização avançada:

1. **Agência Web - Digital Experience:** Landing page com foco em conversão e design moderno.
2. **Cadastro de Clientes (CRUD):** Sistema com back-end em nuvem, praticando as operações de listar, cadastrar e excluir dados via `fetch`.
3. **Calculadora de IMC:** Aplicação funcional para cálculo de massa corporal.
4. **Cadastro de Endereço via CEP:** Automação de formulários consumindo a API de busca de CEP para otimizar a UX.
5. **Controle de Gastos:** Gestão de despesas utilizando conceitos de Programação Orientada a Objetos (POO).
6. **Pet Shop Online:** Landing page desenvolvida com foco em performance e arquitetura baseada em utilitários.

## 🎨 Funcionalidades

* **Navegação Suave:** Menu de navegação com âncoras para Início, Sobre, Projetos e Contato.
* **Integração com WhatsApp:** Script customizado que captura os dados do formulário e redireciona o visitante diretamente para uma conversa privada.
* **Design Responsivo:** Totalmente adaptado para leitura em dispositivos móveis e desktops.
